# DATA — Données mycologiques

Ce dossier contient :
- Fiches descriptives des champignons
- Noms scientifiques et noms communs
- Habitats et périodes de pousse
- Répartition géographique
- Sources scientifiques et documentaires
- Données sur les observations

Chaque information doit être vérifiée et associée à une source fiable.
Ne jamais garantir la comestibilité d'un champignon.
